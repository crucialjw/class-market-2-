# 꿈자람 학급 매점 (class-market)

초등학교 학급에서 쓰는 **포인트 보상 매점** 웹사이트입니다. 칭찬으로 모은 포인트로 학생이 간식·학용품·특권 쿠폰을 신청하고, 선생님이 승인하는 흐름을 한 사이트에서 운영할 수 있어요.

## 도구 이름
**꿈자람 학급 매점** — 설치 없이 `index.html` 하나로 동작하는 정적 웹사이트
(HTML + JavaScript, Tailwind CSS(CDN), Material Symbols, Jua · Noto Sans KR, 선택 사항: Firebase Firestore)

## 간단한 설명
| 화면 | 하는 일 |
|---|---|
| 학생 매점 | 상품 구경, 장바구니, 구매 요청, 보유 쿠폰 사용 |
| 내 통장 | 잔액, 거래 내역, 칭찬 스탬프, 요청 취소 |
| 교사 대시보드 🔒 | 포인트 지급·차감(여러 명 동시 가능), 구매 요청 승인·거절, 학생 명단 관리, 전체 0점 초기화 |
| 상점 관리 🔒 | 상품 추가·수정·삭제, 재고·가격·판매 여부, 공지, 매점 잠금, 구매 제한 |

구매를 요청하면 포인트가 먼저 보관되고, 승인하면 교환 번호가 발급됩니다. 거절·취소하면 포인트와 재고가 돌아옵니다. 포인트는 1점 단위입니다.

## 사용법
1. 사이트 주소를 엽니다. (아이폰·아이패드는 Safari → 공유 → 홈 화면에 추가)
2. **교사 대시보드 → 학생 명단 관리**에서 우리 반 학생 이름을 붙여넣어 등록합니다. 처음에는 "1번~24번"으로 되어 있어요.
3. 학생은 *학생 매점*에서 이름을 골라 구매를 요청하고, 선생님은 *교사 대시보드*에서 승인합니다. 🔒 화면은 비밀번호 4자리가 필요합니다.
4. 새 학기에는 *학생 명단 관리 → 기록 지우고 0P로 시작*을 누릅니다.

## 기기끼리 데이터 연동 (클라우드, 선택 사항)
노트북·태블릿·폰이 같은 데이터를 보게 하려면 [FIREBASE-SETUP.md](FIREBASE-SETUP.md)를 따라 설정하세요. 설정하면 왼쪽 아래에 연결 버튼이 생기고, 공유 링크를 열면 기기끼리 실시간으로 동기화됩니다. 동시에 포인트를 줘도 합산되고, 인터넷이 끊겨도 다시 연결되면 자동으로 저장돼요.

## 개인정보 안내
- 이 저장소에는 학생·교사 이름이 들어 있지 않습니다. 입력한 이름과 포인트는 **클라우드 연동을 켜지 않으면 사용하는 기기의 브라우저에만** 저장됩니다.
- 클라우드 연동을 켜면 입력한 데이터가 **선생님 본인의 Firebase 프로젝트**에 저장되며, 학급 코드를 아는 사람만 접근할 수 있습니다. 학교의 개인정보 방침을 확인한 뒤 사용하세요.

## 비밀번호 바꾸기
`index.html`의 `var PIN='...'` 숫자를 고치세요. 코드가 공개되어 있으므로 보안용이 아니라 학생이 실수로 들어가는 것을 막는 용도입니다.
