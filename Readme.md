# 꿈자람 학급 매점 (class-market)

초등학교 학급에서 쓰는 **포인트 보상 매점** 웹사이트입니다. 칭찬으로 모은 포인트로 학생이 간식·학용품·특권 쿠폰을 신청하고, 선생님이 승인하는 흐름을 한 사이트에서 운영할 수 있어요.

## 도구 이름
**꿈자람 학급 매점** — 설치 없이 `index.html` 파일 하나로 동작하는 정적 웹사이트
(HTML + JavaScript, Tailwind CSS(CDN), Material Symbols, Jua · Noto Sans KR)

## 간단한 설명
| 화면 | 하는 일 |
|---|---|
| 학생 매점 | 상품 구경, 장바구니, 구매 요청, 보유 쿠폰 사용 |
| 내 통장 | 잔액, 거래 내역, 칭찬 스탬프, 요청 취소 |
| 교사 대시보드 🔒 | 포인트 지급·차감(여러 명 동시 가능), 구매 요청 승인·거절, 학생 명단 관리, 전체 0점 초기화 |
| 상점 관리 🔒 | 상품 추가·수정·삭제, 재고·가격·판매 여부, 공지, 매점 잠금, 구매 제한 |

구매를 요청하면 포인트가 먼저 보관되고, 승인하면 교환 번호가 발급됩니다. 거절·취소하면 포인트와 재고가 돌아옵니다. 포인트는 1점 단위입니다.

## 사용법
1. 사이트 주소를 열거나 `index.html`을 브라우저에서 엽니다. (아이폰·아이패드는 Safari → 공유 → 홈 화면에 추가)
2. **교사 대시보드 → 학생 명단 관리**에서 우리 반 학생 이름을 붙여넣어 등록합니다. 처음에는 "1번~24번"으로 되어 있어요.
3. 학생은 *학생 매점*에서 이름을 골라 구매를 요청하고, 선생님은 *교사 대시보드*에서 승인합니다. 🔒 화면은 비밀번호 4자리가 필요합니다.
4. 새 학기에는 *학생 명단 관리 → 기록 지우고 0P로 시작*을 누릅니다.

## 개인정보 안내
이 저장소에는 학생·교사 이름이 들어 있지 않습니다. 입력한 이름과 포인트는 **사용하는 기기의 브라우저에만 저장**되며 GitHub나 서버로 전송되지 않습니다. 같은 기기·같은 브라우저에서만 데이터가 유지되고, 기기끼리 공유되지 않습니다.
